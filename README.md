# SPMUN '26 Website V2

Static GitHub Pages-ready site based on the approved V2 visual baseline.

## Publish on GitHub Pages
1. Create a public GitHub repository named `spmun2026`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Your site will be available at `https://YOUR-USERNAME.github.io/spmun2026/`.

## Editable content
Update `config.js` for registration fee, UPI details, contact details and other administrative values.

## Important
The payment QR is a placeholder and must be replaced with the official QR before launch.
The supplied brochure and delegate handbook are included under `assets/docs/`.
